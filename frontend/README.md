# LeetCode Clone Frontend

Веб-приложение для проведения технических интервью на базе клона LeetCode.

## Функциональность

- Просмотр списка задач с возможностью добавления тегов
- Просмотр списка пользователей с возможностью редактирования рейтинга
- Управление задачами, тегами и категориями для интервьюеров

## Установка

1. Убедитесь, что у вас установлен Node.js версии 14 или выше
2. Клонируйте репозиторий
3. Перейдите в директорию frontend
4. Установите зависимости:
   ```bash
   npm install
   ```

## Запуск

Для запуска приложения в режиме разработки выполните:
```bash
npm start
```

Приложение будет доступно по адресу http://localhost:3000

## Технологии

- React
- TypeScript
- Redux Toolkit
